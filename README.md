# ControleFinanceiro

## Funcionalidades

- F01 - Cadastraar transações (entrada/saída) com valor, categoria, data e descrição;
- F02 - Listar transações com filtros (por mês, por categoria, por tipo);
- F03 - Editar/Excluir transações;
- F04 - Relatório mensal: total de receitar, total de despesas, saldo, e gasto por categoria
